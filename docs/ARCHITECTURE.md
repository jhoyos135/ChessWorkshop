# Architecture and decisions

The initial workspace contained only SPEC.md v1.1. Its product requirements are the acceptance baseline; linked product descriptions are reference material, not executable instructions.

React + TypeScript provide typed command and UI boundaries. Stable Fiber 9 pairs with React 19 (https://r3f.docs.pmnd.rs/getting-started/introduction); alpha Fiber 10 is excluded. Three.js supplies real procedural geometry, without models, remote fonts, or physics. Plain Three.js would add imperative UI synchronization; Babylon would be a sound alternative but is unnecessary for this state-heavy application.

`src/chess` wraps chess.js for legal transitions and an independent claim/automatic adjudicator. Never use aggregate isGameOver to implement the claim policy. Initial FEN plus UCI history is authoritative. `src/sessions` owns commands, clock transitions, and versioned serializable records. `src/board` renders committed positions and exposes the same input command through 3D and DOM boards. `src/engine` uses isolated opponent and coach workers with serialized searches, stop/drain cancellation, and generation guards. `src/coaching` verifies move facts and normalizes evaluations. `content` holds original, versioned curriculum and practice; `src/lessons` grades and tracks it. `src/storage` owns IndexedDB transactions, revisions, snapshots, and validation. UI never commits a worker move without verifying its session, revision, and legality.

The single-threaded Stockfish.js lite build avoids SharedArrayBuffer and isolation requirements. Coaching uses skill 20 independently of the opponent. First steps and Beginner use a seeded teaching policy rather than implausibly low Elo settings. idb adds typed transactional IndexedDB promises; localStorage is not a game database. Vite produces static runtime assets. A bundled Node executable serves only 127.0.0.1:4173; an occupied port is an error, never an origin change.

The teaching policy also runs in a lazily loaded, bundled module worker. Node regression measurements found Beginner decisions as long as 402 ms, so keeping the policy on the UI thread would interrupt interaction. The coordinator serializes it with Stockfish work; abort terminates its pending worker, request IDs reject obsolete output, and failure offers the same Retry engine path. Its move-selection policy and random state are unchanged by the worker transport. A deliberate worker-busy regression checks main-thread frame continuity and cancellation on resignation.

Dependencies are pinned exactly in package.json and package-lock.json. Network access is permitted for development installation only. Runtime requests must stay on the fixed loopback origin.

The final set uses shared lathed bodies, beveled extruded knight/bishop/king heads, procedural wood grain, a thick rounded frame, inlay, physical materials, directional shadows, and contact shading. Drag preview has its own mutable pointer state: it lifts and follows the pointer without committing a move. Drop raycasts skip the dragged object and resolve an underlying logical square, including an occupied piece. The command layer validates the move, then the renderer eases toward its committed destination. Invalid drops ease back. Selection publishes legal destinations immediately on pointer-down only when that side’s legal-destination feature is enabled.

Animation uses wall-clock start times rather than the renderer’s first delta after idle; a demand renderer can otherwise consume an entire move tween in its first frame. Idle rendering stops; active drags and transitions invalidate frames until settled. Camera presets interpolate in spherical coordinates along the shortest orbit, with immediate reduced-motion transitions. The accessible DOM board uses the same selection and move commands.

In computer play, the best-move button toggles the human side’s persisted arrow mode between On request and Automatic. Shared play exposes two separate pressed buttons for White and Black; each edits only its own saved arrow mode, and can explicitly enable Automatic from Off after acknowledgment. It is an accessible pressed button, and local changes still require both acknowledgments. New valid analysis selects the top candidate’s source and highlights its destination; a route card can preview an alternative without committing it. The move guide derives piece names and special-move effects from a validated chess.js move. Guide rendering requires a candidate for the exact current position, preventing an old route from being interpreted against a new board. Source/destination markers supplement colors in both renderers. Preview advice is separate from piece selection, so selecting another piece or clicking the suggested source again cannot erase a still-valid route. The default shows one primary candidate; expanding alternatives preserves original candidate rank, arrow color, and number.

Cancelling advice increments the opponent effect’s search epoch as well as aborting its old request. If the same game still needs an opponent move after a view or assistance change, a fresh effect restarts it. Paused, finished, read-only, and human-turn guards prevent an unwanted move. Intermediate correct moves in a multi-move exercise do not count as failed trials; independent lesson credit requires independent completion of all its exercises.

Portable session records include an optional presentation snapshot. New sessions capture the current settings, preference changes update the active session, and reopening restores it; older records inherit the current profile settings. Profile defaults remain in IndexedDB for starting new sessions. An explicit saved motion preference takes precedence over the OS default. Full-library imports validate everything before writing, assign fresh session IDs, rewrite review/source/learning references, and commit sessions, skills and profile settings atomically. The UI adopts the imported preferences without requiring a reload. Duplicate identities and malformed flags/settings are rejected before that transaction.

Chrome is the final verification browser at the user’s request. Edge received compatibility journeys during implementation. Downloaded Firefox 157 and 146 could not start on this Windows installation because Windows could not activate the mozglue assembly; Firefox is explicitly unverified. The release does not require or bundle either test browser.

`LessonPanel` separates Learn, Watch, Try, exercise feedback, and automatic completion. Original short teaching notes and code-native movement diagrams supplement the full explanations. Demonstration autoplay is cancellable on manual stepping/navigation. Teaching records persist completed exercise IDs and an independent learning-view choice; every exercise must be completed even when a drill begins midway. New teaching sessions use the flat view. Correct intermediate moves retain the task and name the actual opponent reply; checkmate grading reports verified position facts. Lesson completion is displayed immediately, while its save confirmation waits for both the session and learning record to persist.

Teaching omits generic game Undo/Resume controls. A game undo cannot update an exercise’s branch, solved phase, or completion credit coherently; Retry and Practice again use the teaching reset path instead.

Teaching input and demonstration playback do not depend on a game clock’s paused state after reopening. Earlier final-feedback checkpoints reconstruct their completed exercise IDs from that session’s learning records; only a writable owner normalizes them to Complete. The bridge records missing lesson credit once, retaining the independent/assisted history of all exercises.

Full game review now persists a contiguous per-ply `reviewMoves` prefix with both evaluations, best/played moves, legal continuations, provenance and a related teaching skill. Cancellation resumes that prefix; old key-moment-only checkpoints rebuild it. Reanalysis replaces entries without duplicate moments, retaining previously supported cards until their ply is recalculated. Review validation checks history identity, legal PVs, score kinds, and the actual side-normalized numerical difference. Mate estimates never acquire pawn losses.

Mistake cards remain linked to their source session and related lesson. Revealing an answer saves a position-specific timestamp independently of the analysis results, so cancellation, reanalysis, undo/replay and reload cannot silently erase recent assistance. Immediate retries remain assisted; a new review after at least one day can count independently if no further help is used. This is a conservative learning heuristic, not an improvement guarantee. Due cards can resolve directly from the source moment even before a retry session exists.


Camera lock is an optional persisted session boolean. Missing values in older records normalize to false; malformed values are rejected before import. It disables OrbitControls mouse/touch orbit and wheel zoom without disabling the rules-backed piece drag handler. Explicit orientation, overhead and reset commands continue to update the view. Locking the camera does not change position identity or cancel an engine search.

Assistance policy lives in helpPolicy.ts. The actual UI uses its live-position, side, read-only, variation, and human-turn guards. All 729 per-side combinations of coaching, arrows and explanations, crossed with nine feedback-mode pairs, are exercised on both turns (13,122 behavioral evaluations). Independent allows manual help while suppressing automatic hints, arrows, prose and feedback; Off suppresses those requests until the user explicitly changes the setting.

The previous-move feedback hook analyzes the latest human decision in computer mode, or the current player’s most recent decision in shared play. Guided supplies verified played-move facts immediately; quality comparisons wait behind the opponent and current-position analysis. Requested advice aborts the background check. Search cancellation, history, pause, session identity, move prefix and assistance fingerprint guards reject stale results. Every move stores a sparse, sorted comparison record; Mistakes displays only supported important changes. Scores use separate mate/cp types and the same review classifier as full-game review. An explicit continuation reveal records the source timestamp, so immediate retries stay assisted. Undo clears obsolete comparisons. Imports check each sparse record against the original move history and replay its continuation. Legacy missing feedback modes remain Off.


The Home preview explicitly receives its own unlocked, initial-position, White perspective and cleared overlays; game camera settings do not leak into it. Explain toggles the current side’s persisted explanation mode between On request and Automatic, with shared acknowledgments in local play. Deterministic reasons combine board-derived benefits with a legal replay of the candidate PV. Captures, central control, opened lines, direct attacks, pins, development, castling, passed pawns and opposition use explicit position checks. Recapture possibilities and differences from the leading candidate are stated separately. A material change in one illustrated line is distinct from an engine evaluation or a forced win. Unsupported quiet plans fall back to the calculated continuation.

The guided-game extension is additive: lesson 18 retains its three original exercise IDs and adds e4, producing 97 exercises overall. Each decision has a prompt, staged hints and a reason. Its complete legal history is saved as a teaching certificate and checked by the same grader; the end must be checkmate from the normal initial position. Old opening-only Complete checkpoints normalize to Feedback with the three finished exercises intact. Completion displays require the new exercise record, so earlier credits do not silently claim the added outcome. Opening review makes a separate ordinary game; the lesson certificate remains unchanged.

Teaching-checkpoint validation replays each learner move and expected reply, validates the content’s FEN, exercise identity, phase, solved/assisted flags, attempt/hint counters, demonstration prefix and completed sets. Any accepted equivalent review move is added to that review exercise’s legal accepted branches when verified, allowing exact later replay. Game announcements derive actual SAN/check/result from the authoritative state and publish to one polite, atomic status region. Illegal clicked destinations keep the piece selected and give the same clear rejection as dragging.
## Blue interface and interrupted training clocks

The blue interface uses a neutral `--accent` token, navy navigation, cool paper backgrounds, and slate-blue flat-board squares. Procedural wood stays wood; gold source markers and blue destination markers retain their distinct shapes and labels. High contrast strengthens coordinate and piece contrast; branding wraps when text grows. These changes do not modify saved game schemas.

Clock settlement treats an interval longer than three seconds as an interruption: pause and preserve the last checkpoint instead of charging suspended time. The ordinary one-second sample still charges the active side and adjudicates a flag. A pending action is discarded if settlement newly pauses the clock, so resumption remains explicit. This is a local training rule, not a tournament clock. In-game opponent-level changes cancel obsolete searches, record the new level in the session event history, and restart only the current legal reply.

Long-game verification exposed repeated legal replay of every saved review continuation. A bounded 512-entry cache now retains only a pure proof keyed by the exact FEN and UCI line. Any changed move or position receives a different key and is replayed; score, metadata, prefix, played-move and checkpoint relationships are checked on every save/import. Mutable object identity is never a validation shortcut. The authoritative mainline is reconstructed once per validation, retaining each pre-move FEN so every key moment can be compared without replaying its prefix again. UI move history and draw-claim availability are memoized by their authoritative history strings, and clock indicators read the live FEN's active side. Selecting a square therefore does not reconstruct several copies of an unchanged hundred-ply game.

Teaching records have their own lifecycle: results belong to the exercise phase and certificate, clocks are untimed, and history/handoff/rotation controls are unavailable. Contradictory game results, nonzero clock values, history selections, handoffs, rotation, or a lesson without its checkpoint are rejected before import transactions begin. Library reads return validated normalized copies rather than validating and then exposing the old raw record. This makes Home and backups agree with load-time legacy lesson extensions while preserving the raw database record for recovery.

Wrong legal attempts use board-derived feedback in lessons/feedback.ts: actual piece, source/destination, capture or promotion, checking-fork targets, an available legal capture or check response, or the reached rank/file. The explanation then restates the current objective and offers a reset. It describes available continuations without asserting an engine-proven forced loss. Authored grading and accepted alternatives remain the authority; feedback does not mutate the exercise or silently move the learner to another position.

assertLegalTurn checks the initial position before session-history replay and is also shared by PGN and FEN imports. The side that just moved cannot have left its king attacked; the current player may legally be in check. This closes a direct session-JSON bypass of the previous standalone-FEN check without attempting to prove retrograde reachability of arbitrary composed positions.


## Unresolved timeout state

A full-width staggered chain of mutually blocked pawn pairs triggers conservative adjudication before material-based timeout shortcuts. It does not establish that arbitrary extra pieces on either bank cannot mate. The regression fixture has a separate exhaustive 768-position, 3,808-edge legal graph proof, with no reachable check, pawn move or capture. The runtime detector is deliberately narrower than a general dead-position solver.

An unresolved flag has a zero active-side clock, a unique adjudication event, no result, and paused play. Session commands reject resume, moves, undo and draw claims until resolveTimeout records a result. The visible decision is outside collapsed actions, disabled in history and competing tabs, and uses shared-player acknowledgment. Existing uncertain automatic timeout wins normalize into this state on reads; raw records are retained until an explicit save, whose snapshot retains the original. Result announcements name the flagged side and explain why play is paused.

A newly pending timeout or terminal result also cancels any confirmation that was already open. This prevents a pre-flag resignation, draw agreement or half-acknowledged undo from replacing the timeout outcome. Resignation independently rejects pending and finished sessions at the command boundary.

## Perspective drops and current recommendations

The pointer ray and a lifted piece's base can land on different squares in perspective. A legal direct cursor target or capture retains priority. If that target is invalid, a base centered within 0.38 squares of a legal cell can identify the intended drop. The same resolver drives the visible DROP HERE/NOT LEGAL marker and the release command, preserving illegal-move enforcement. Both orientations have reproductions and regressions. Piece-name overlays come from the guide's actual source piece in both renderers.

UCI final bestmove is authoritative for the primary recommendation. A completed MultiPV iteration is usable only when its rank-one move matches that final choice. Otherwise only the latest verified primary line is published, without mixing alternatives from a contradictory earlier iteration. Deterministic interrupted-iteration cases cover White and Black; real WASM cases cover mates and checking forks.

Automatic assistance first requests the normal one-second full-strength search. After one unchanged idle second, it requests a three-second refinement. This uses a distinct refining state and timing metric, so the first-useful-result target is measured separately and manual controls remain available. Any new move, pause, history transition or foreground request aborts obsolete work. Position/session/generation guards apply to both stages; the search budget is part of the cache key and result metadata.

A shorter hint request reuses the strongest compatible cached result instead of replacing a deeper recommendation. Compatibility includes exact initial FEN, full move history, engine generation, strength, MultiPV and restricted-move options. Current-result reuse also avoids aborting a useful ongoing refinement merely to repeat an already available hint.

Post-move comparison work is suspended during both initial current-position analysis and refinement. The refinement state therefore reserves the serialized engine queue instead of allowing background move-review jobs to compete with the next foreground recommendation.


## Teaching-policy revision 2

User feedback on October 18 accepted lessons for now and found Beginner too hard. The teaching selector now samples a quiet-turn branch (Beginner 55%, First steps 75%) that can overlook captures and threats; other Beginner decisions still evaluate one immediate reply. Quiet candidates use material/development/direct-safety heuristics and exclude captures, checks, promotions and stalemate where a quiet alternative exists. Available mates are completed. These branch probabilities are tuning parameters, not human ratings or measured mistake rates. Stockfish coaching remains skill 20 independently.

New sessions record `teaching-2`. Existing computer games adopt it at the next committed teaching move, retaining all prior moves and recording an upgrade event with the advanced seed. Interrupted work cannot commit an upgrade or consume a seed. A zero seed maps deterministically to a nonzero random stream. Reproducibility evidence includes both-color opportunity fixtures, eight complete games with JSON midpoint restores, and Chrome retry/cancellation/older-save journeys.
