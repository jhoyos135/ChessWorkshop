# Credits, sources, and licenses

Chess Workshop application code is provided under GPL-3.0. Original lesson wording, composed exercise/puzzle positions, and explanations are dedicated under CC0-1.0. The procedural Staunton-inspired geometry and generated wood textures are original project assets. No imported models, fonts, sound recordings, analytics, or remote inference services are used. Optional audio is synthesized locally.

Runtime dependencies are pinned in package-lock.json: React and React DOM 19.3.1 (MIT), Fiber 9.8.2 (MIT), Three.js 0.186.1 (MIT), chess.js 1.4.0 (BSD-2-Clause), and idb 8.0.4 (ISC). The release includes dependency license notices and a dependency manifest. Tooling dependencies are recorded separately by npm. The bundled Node.js executable is the tested Windows x64 20.19.4 runtime, with its complete license notices.

Stockfish.js 19.0.1 is developed by Nathan Rugg, Chess.com, and the Stockfish contributors, under GPLv3. The unchanged lite single-threaded JavaScript and WASM assets are copied from the exact npm package. The versioned asset manifest records SHA-256 hashes. Its startup identifies Stockfish 19 lite. It uses the lite neural network by Chris Bao (sscg13), `nn-61e7af4bb97d`. This is a smaller engine than full Stockfish; coaching means its strongest available settings, not full-build strength.

Exact upstream source: https://github.com/nmrugg/stockfish.js/tree/0d5dd7944f88c817c07a26bc4fb1905d5f9c46d6, tag `v19.0.1` (annotated tag object `8d9ca57043594a8fa6ae0b73fb685d9105bf51df`). A source archive is included in `sources/stockfish.js-v19.0.1.tar.gz`; matching network weights are in `sources/nn-61e7af4bb97d.nnue`. The weights come from https://tests.stockfishchess.org/api/nn/nn-61e7af4bb97d.nnue. The archive includes the build script and Makefiles. Use upstream’s Emscripten setup and `node build.js --single-threaded --lite -f`; retain the bundled network in the source directory expected by that build. No engine modifications were made.

Rules reference: FIDE Laws of Chess, adapted to the explicit local training claim and clock policy in SPEC.md. Product comparisons in SPEC.md informed scope; no proprietary lesson text, artwork, or puzzle records were copied. The 100 additional puzzles are original deterministic compositions screened for legal starts, solutions, and stated tactical predicates. Curation seed and provenance are in each record and in `scripts/curate-puzzles.ts`.

The additive complete-game exercise uses the standard Légal’s-mate move pattern, with original decision prompts, explanations and grading. The pattern is named in the Chess.com Team’s [Exclusively Checkmates course](https://www.chess.com/lessons/exclusively-checkmates). No course text, exercise files or assets were copied. Legality, replies and the final result are verified locally with chess.js. The remaining exercises and all 100 additional puzzles are original project compositions.
