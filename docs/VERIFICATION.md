## Performance and engine

Machine: Windows 11 Home, Intel Core Ultra 9 185H (22 logical processors), approximately 32 GB RAM, Intel Arc graphics through ANGLE/D3D11. Chrome 155, 1920×1080, capped pixel ratio, shared geometry, demand rendering. Exact values, sample sizes, and limitations are in [performance.json](evidence/performance.json); reduced quality is measured separately in [performance-low.json](evidence/performance-low.json). These are local headless frame-cadence measurements, not a universal hardware or physical-monitor guarantee.

The final full-quality run recorded 60.54 FPS during orbit, 252 ms first interaction, 12.9 ms p95 input, 83.7 ms p95 saves, and 1.34 seconds p95 first-useful coaching. Reduced quality recorded 60.32 FPS, 251 ms first interaction, 12.3 ms p95 input, 337.6 ms p95 saves, and 1.25 seconds p95 first-useful coaching. Targets passed. Background refinement was measured separately at 3.01/3.02 seconds; it does not replace the first-useful-result target. These are separate local cold runs with 19 save samples each. Timing jobs ran sequentially on the final build; exact hashes and sample sizes are in the JSON files.

A separate longer-game check in [review-performance.json](evidence/review-performance.json) reviewed 80 actual WASM plies and then played 20 further plies. All 80 records survived in the 130,848-byte, 100-ply session. Across 20 saves and 24 selections, p95 save acknowledgment was 21.3 ms and input feedback 13.0 ms. Review took 66.31 seconds at 350 ms per requested search. This deterministic flat-board check does not measure physical-monitor cadence or human learning.

[performance-refinement-regression.json](evidence/performance-refinement-regression.json) retains the 2.17-second first-result outlier observed while background move review competed with refinement. Move review now waits during either current-position search stage; the final first-result run returned within 1.34 seconds and refinement within 3.02 seconds.

The [recorded regression](evidence/review-performance-regression.json) first measured 838.6 ms saves and 111.2 ms input with richer explanations. Repeated continuation replay, repeated key-moment prefix reconstruction, and repeated UI history/draw-claim work caused the excess. Exact-value legal-line proofs, one mainline pass, and memoized display calculations removed it. A warmed proof does not skip metadata or history checks; changed continuation and forged metadata tests pass.

[teaching-games.json](evidence/teaching-games.json) and [teaching-games.pgn](evidence/teaching-games.pgn) record eight paired seeded games and 598 legal plies. Beginner won all eight against First steps; no game reached the 200-ply limit. The same-seed replay matched every move and final random state, with seven midpoint restores. First steps policy p95/max was 13.2/17.8 ms (250 ms budget); Beginner was 307.9/402.0 ms (500 ms budget). Calculation timing excludes UI pacing, adjudication and disk I/O. Both policies run in a local worker so those calculations do not block the interface; an artificial 1.2-second busy-worker test verifies frame continuity and resignation cancellation. These games are regression evidence, not human calibration.

[engine.json](evidence/engine.json) records the exact Stockfish 19 Lite WASM handshake: Threads 1, Skill 0–20, MultiPV 1–256, Elo 1320–3190, matching network, legal bestmove, startup/search timing, and Node process memory. ## Reproduction and delivery

Run `npm ci`, `npm test`, `npm run validate:content`, `npm run build`, and `npm run test:browser`. `npm run verify:teaching` reproduces the paired deterministic teaching-policy games. `node scripts/check-engine.mjs` records the exact native WASM handshake. `node scripts/measure.mjs` measures full quality; add `--low-quality` for reduced quality. `npx tsx scripts/verify-timeout.ts` reproduces the blocked-fixture proof and portable test session. `npm run package` assembles the Windows folder. `node scripts/verify-package.mjs` verifies every SHA-256 entry and launches the package using its bundled runtime; it also checks the actionable occupied-port error. `pwsh -File scripts/verify-archive.ps1` verifies every archive entry against the embedded manifest and matches that manifest to the assembled folder.

The package contains production assets, Windows launcher/Node runtime, source, original library, upstream engine source/network, dependency notices, guide, report, and SHA-256 manifest. User saves are not embedded; use portable JSON backups. Package smoke results are in [package.json](evidence/package.json).
